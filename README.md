# 书帖结构复原台（离线版）

供古籍修复人员与手稿编目员使用的**离线**书帖（quire）结构复原工作台。
纯 Python 标准库后端 + 原生 HTML/CSS/JS/SVG 前端，无任何第三方依赖、无需联网。

## 启动

```bash
python3 server.py
```

然后用浏览器打开 <http://127.0.0.1:8371>。

- 数据保存在程序目录下的 SQLite 文件 `restoration.db`（首次启动自动创建）。
- 首次打开且库为空时，会自动播种两个相互对照的示例假设（含缺叶、悬空单叶、
  嵌套冲突、证据矛盾、一片待位残片，以及完整的证据链：互斥同证、悬空引用、
  自我证明、循环依赖与已合并归档记录），可直接体验全部功能；删除假设后即为空白。
- 仅监听本机回环地址 `127.0.0.1`，不向网络发送任何数据。

## 工作概念

| 对象 | 说明 |
|---|---|
| **双叶 bifolio** | 由两张叶配对而成，嵌套时分居书帖对应层位（层位和 = 帖内叶数） |
| **单叶 single** | 未配对的完整叶；奇数帖中缝的单叶合法，其余位置须有接缝/托裱证据 |
| **残片 fragment** | 不参与双叶强校验；选中后由系统按现有约束**筛选候选位置**，证据不足时并列保留、不自动定案 |
| **书帖 quire** | 叶的有序容器；可嵌套多双叶 + 至多一中缝单叶（奇数帖） |
| **假设 hypothesis** | 一整套复原方案的快照，可保存多个、互相对照 |

每个对象都有 **确定 ✓ / 存疑 ？** 状态；折痕、接缝/托裱、线孔数量、纸张连续、
针脚相合等装订证据逐叶/逐双叶记录。

## 三栏界面

- **左栏**：添加双叶/单叶/残片/书帖（可点击，也可直接拖入画布）；待编叶件托盘；
  残片候选位置；操作模式（只重排存疑项、合帖、拆帖）。
- **中栏**，三视图联动：
  - **嵌套剖面**：SVG 书脊纵剖图，同色弧线 = 同一双叶，弧线相套即嵌套；
    弧线虚线 = 存疑双叶；金色圆点 = 线孔；蓝色竖条 = 接缝；红色感叹号 = 冲突。
  - **叶序带**：装订顺序的水平带，叶块可拖拽换位/跨帖移动；
    拆帖模式下点击叶间 ✂，合帖模式下点击帖间 ⇄合 圆钮。
  - **书帖卡**：逐帖列出层位、叶码、证据徽标与状态，可改名、锁定、拆/合、删除。
- **右栏**：详情编辑（叶码、正背面题记、折痕、接缝、线孔、备注、配对、状态）；
  实时校验列表（点击可定位到对应对象）；假设管理。

## 证据链模块（独立装订证据记录）

右栏「证据链」标签管理**独立于叶件/双叶对象**的装订证据记录：线孔、折痕、接缝、
叶码连续、纸张特征等逐条建档，填写来源说明、可信度（高/中/低）与「待核验 / 已确认」状态，
并可关联任意叶片、双叶或书帖。每条记录有**版本历史**，关键字段修订自动留痕。

### 结论与关系

每条证据可标注它**支持 ▲ 或反驳 ▼** 的三类结论：

| 结论类型 | 说明 |
|---|---|
| **配叶** | 哪两叶构成同一双叶（现结构中的双叶自动成为系统结论；另立意见建为「候选配叶」） |
| **层位** | 某叶位于某帖某层位（含中缝单叶） |
| **叶序** | 某叶应在某叶之前（帖内/跨帖） |

系统按当前假设自动展开每个结论的**直接证据与逐级推导依据**（证据可把其他证据列为依据，
形成推导链；「展开推导依据」按钮向上递归）。

### 关系图（SVG 力导向）

叶件/双叶/书帖详情中的「🕸 证据链关系图」、或证据链标签的「关系图（全部）」打开：

- 三列节点：**画布对象（左）— 证据记录（中）— 结论（右，实线=现结构，虚线=候选）**。
- **拖连**：在证据节点上按住拖到结论节点建立「支持」；按住 Alt 拖为「反驳」；
  拖到另一证据节点 = 添加推导依据。建立前预览受影响结论与将出现的冲突。
- 绿色箭头支持、红色箭头反驳、灰虚线为依据/关联；红色描边 = 冲突标记。
- **合并重复记录**：工具栏进入合并模式，依次点两条证据，关系迁移、去重、依据改指，
  旧记录归档（保留版本，可在列表底部追溯）。
- **反向定位**：点对象节点或证据列表中的对象徽标，即回到三栏画布并选中对应叶件/双叶/书帖；
  双击证据节点直接打开记录编辑器，双击候选结论可删除。
- 滚轮缩放、空白拖动漫游、「复位视图」。

### 冲突识别（只标记，不改动结构）

分析在每次编辑后即时运行，冲突以红框/徽标显示在记录、关系与校验摘要上：

1. **同一证据同时支持互斥结论**（如同证既支持现状配叶又支持候选配叶）；
2. **引用已删除对象**（叶件/双叶/书帖删除后，证据与关系保留，标「悬空」，可追溯）；
3. **自我证明**（证据把自身列为推导依据）；
4. **循环依赖**（依据图中的环，Tarjan 强连通分量识别）。

删除任何画布对象都不会改动证据链，只增加悬空标记。

### 假设比较 / 导入导出 / 打印

- 切换假设时，「比较」第 ④ 部分给出**证据链增减**：新增/移除的证据记录与结论关系、
  待核验→已确认的状态变化、五类冲突计数差异。
- 导出 `quire-restoration/v1` JSON 完整包含 `evidences / claims / links`（含版本历史与来源），
  导入时自动补齐缺失字段。
- 打印图新增「证据链记录」页：逐条列出来源、可信度、状态、版本号、支持/反驳的结论与冲突标记。

### 证据链 JSON 片段

```json
{
  "evidences": [{
    "id": "e...", "title": "首帖外叶三针等距", "kind": "holes",
    "subjects": ["l:<叶id>", "p:<双叶id>"],
    "source": "目验 2026-09-02；修复档案 甲-07",
    "credibility": "high", "status": "confirmed",
    "basis": ["<其他证据id>"], "archived": false, "mergedInto": null,
    "history": [{"at": "…", "note": "初记两孔，复核改三针", "source": "…", "credibility": "medium"}]
  }],
  "claims": [
    {"id": "c...", "kind": "pair", "a": "<叶id>", "b": "<叶id>"},
    {"id": "c...", "kind": "place", "leaf": "<叶id>", "qid": "<帖id>", "pos": 2},
    {"id": "c...", "kind": "order", "a": "<叶id>", "b": "<叶id>"},
    {"id": "c...", "kind": "note", "text": "自由记述的复原意见"}
  ],
  "links": [
    {"id": "lk...", "evidence": "e...", "target": "~pair:<双叶id>", "stance": "support"}
  ]
}
```

系统结论使用合成 ID（`~pair:` / `~place:` / `~order:` 前缀），不写入文档；
指向已不存在合成 ID 的关系即「引用已删除对象」，只标记、不改动。

## 实时校验

每次编辑后即时运行，右栏「校验」标签红点计数，问题分六类（可按类开关过滤）：

1. **缺叶** —— 叶码不连续，标出缺失叶码及「帖内 / 跨帖」位置（支持阿拉伯与中文数字）。
2. **重号** —— 同一叶码出现多次。
3. **悬空单叶** —— 单叶既不在奇数帖中缝，又无接缝证据；提示「既不在中缝，也无接缝证据」。
4. **嵌套冲突** —— 同一双叶两叶不在对应层位（层位和 ≠ 帖叶数）、或分处两帖。
5. **证据矛盾** —— 如已确认双叶两叶均无折痕、线孔数量相差过大、
   单叶却录有折痕、残片被配入双叶等。
6. **叶序不衔接** —— 倒置（另计 warn 级提示）与重复占位（同一叶不能占两个位置）。

## 候选位置（残片）

选中残片后，系统对每个「帖 × 插入间隙」做**假设性放入并重算校验**，
凡不引入新错误的位置都列为候选，并给出支持理由（叶码衔接、线孔相合、
可接缝邻叶、可居中缝）。理由为空的位置以浅色标出（仅“不冲突”，非证据支持），
同时始终并列「独立成帖」候选——系统只筛选，不替你定案。

## 锁定与只重排存疑项

- 书帖卡上勾选「锁定已确认关系」可锁帖；左栏开启「只重排存疑项」后：
  已确认叶件/双叶、已锁帖均禁止移动与编辑，候选位置也不再进入锁定帖。
- 解锁或把对象改回「存疑」即可重新操作。

## 假设：多方案、比较、导入导出

- 顶栏输入名称后「保存」，「另存为」生成新假设；「假设」标签中双击切换、勾选删除。
- 「比较」任选两个假设，输出：① 逐帖叶序对照表（黄块为差异），
  ② 配叶差异（拆对/新配），③ 各类型冲突数量差异。
- 「导出」生成 `quire-restoration/v1` JSON；「导入」读取同格式文件替换当前工作稿。

## 打印图

「打印图」生成 A4 风格报告，含：题名/假设/时间题头、图例（双叶弧、线孔、接缝、
折痕、存疑、冲突、锁定）、每帖的剖面 SVG、层位—叶码—正反面题记—证据—状态—校验
明细表、待编区与备注；红色标注存疑项。用「打印 / 存 PDF」走浏览器打印。

## 快捷键

| 按键 | 功能 |
|---|---|
| Ctrl/⌘ + Z | 撤销 |
| Ctrl/⌘ + Shift + Z / Ctrl+Y | 重做 |
| Ctrl/⌘ + S | 保存当前假设 |

所有结构性操作（增删、拖拽换位、配对/拆对、拆帖/合帖、状态切换、锁定）均纳入
撤销/重做栈（上限 100 步）。

## 文件结构

```
server.py            标准库 http.server + sqlite3 后端（REST：/api/hypotheses）
static/index.html    界面骨架
static/style.css     样式（含 @media print 打印样式）
static/app.js        全部前端逻辑：状态/撤销栈/校验引擎/候选筛选/SVG/拖拽/比较/打印
restoration.db       SQLite 数据文件（运行后生成，可直接备份/拷贝）
```

### 文档 JSON 结构（导入导出格式）

```json
{
  "format": "quire-restoration/v1",
  "name": "假设名称",
  "document": {
    "version": 1,
    "title": "卷子题名",
    "leaves": [{
      "id": "l...", "folio": "十二",
      "faces": {"recto": "正面题记", "verso": "背面题记"},
      "status": "confirmed|doubt", "frag": false, "note": "",
      "evidence": {"fold": "none|outer|inner", "seam": false, "holes": 3}
    }],
    "pairs": [{
      "id": "p...", "a": "叶id", "b": "叶id",
      "status": "confirmed|doubt",
      "evidence": {"join": true, "threadMatch": true}
    }],
    "quires": [{"id": "q...", "name": "首帖", "locked": true, "leaves": ["叶id..."]}],
    "notes": ""
  }
}
```

层位规则：帖内叶序数组下标 `i`、`j` 满足 `i + j = 叶数 - 1` 的两叶构成对应层位；
奇数帖正中间下标为合法中缝单叶。
